## 홈 주변 매장 (기능1)
- 홈 첫 줄 "내 주변 매장": `GET /user/stores/map/radius` (반경 1km, 가까운 순 10개), 카드 두 번째 줄에 "음식 종류, 거리"
- 위치 권한이 없으면 강남역 기준으로 보여주고 설명에 안내. 1km 안에 없으면 지도 안내 문구
- "지도로 보기"로 `/map`. 추천 줄 순서를 와이어프레임대로 (내 주변, 오늘 저녁, 지금 웨이팅)
- StoreCard 가 주소 없는 매장(MapStore)도 그리게 `StoreCardData`, compact `meta` 추가

## 테스트 결제 안내 (기능64)
- 예약금 결제 화면 위에 "테스트 결제예요. 카드 정보를 넣어도 실제로 돈이 나가지 않아요." (토스 라이브 키가 아니면 표시, `isTestPayment`)
- 결제 상세는 서버 `receiptNotice` 로 이미 안내 중이라 그대로

## 점주 매출 보기 (기능32)
- `GET /api/owner/stores/{storeId}/sales?from=&to=` (SalesResponse) 연동, 10/29 에 지운 화면을 새 계약에 맞춰 다시 만듦
- 기간 칩: 오늘 / 최근 7일 / 이번 달 / 직접 선택(날짜 2개). 순결제액, 승인된 결제, 환불 차감
- 날짜별 순결제액 막대: API 가 기간 합계만 줘서 하루씩 조회 (31일 이하일 때만)
- 서버 `notice`(모의 집계 안내)를 그대로 표시, 승인일 기준 안내 문구
- 점주 매장 홈 더보기에 "매출 보기"
- MSW: 매출 API, 혼술 이자카야 최근 40일 이용 완료 예약 일부에 테스트 결제 시드 (목 DB `v7`)

- `shared/ui/Skeleton`: Skeleton, SkeletonGroup(화면 낭독기에 "불러오는 중" 한 번), SkeletonText, ListSkeleton, ShelfSkeleton, DetailSkeleton

- 화면 단위 스피너를 스켈레톤으로 교체 (홈, 검색, 매장 상세, 지도 목록, 마이다이닝, 이용 현황, 결제 내역과 상세, 점주 목록과 설정 화면 등)
