# 2026-11-09 와이어프레임 공통 디자인 반영

Figma 와이어프레임(Wireframes 2026-11-03)과 팀 리뷰 댓글에서 정한 공통 화면 규칙을 코드에 옮겼다.

## 바꾼 것

- 매장 목록 응답(`StoreSummaryResponse`)의 `imageUrl`을 `Store` 타입에 추가했다. 백엔드는 이미 내려주고 있었다.
- 매장 카드: 카테고리 이모지 대신 대표 사진 1장을 보여준다. 사진이 없으면 회색 사진 자리 아이콘이 나온다.
- "웨이팅 가능"을 배지 상자 대신 갈색 글씨로만 표시한다 (댓글: 박스에 넣을 필요 없음).
- 홈 음식 종류: 이모지 타일 격자를 가로로 넘기는 칩 줄로 바꿨다 (댓글: 이모지가 AI 느낌).
- 예약 가능 시간 슬롯 테두리를 진한 갈색에서 `border-strong` 회색으로 바꿨다 (검색, 매장 상세, 예약 시트).
- 매장 상세
  - 오늘 영업시간 옆 "요일별 보기"를 누르면 월~일 영업시간과 쉬는 시간이 펼쳐진다 (댓글: 다른 날 영업시간).
  - 리뷰에 최신순/별점순 칩을 달아 `GET /api/user/stores/{id}/reviews?sort=LATEST|RATING`을 호출한다.
  - 공공 매장 안내 문구에서 "·"를 뺐다.
- 결제 상세: 결제 수단을 "토스페이먼츠"로 고정 표시한다 (카드 상세 정보는 쓰지 않기로 함).
- MSW 목: 매장 7곳에 와이어프레임과 같은 사진(`public/mock/stores/*.jpg`)을 넣고, 매장마다 앞의 리뷰 두 개에 사진 1장을 붙였다.

## 확인

- `tsc --noEmit`, `oxlint`, `vitest run` (31개) 통과
- MSW 목으로 홈, 매장 상세(요일별 보기, 별점순), 조건 검색 화면을 띄워 확인. 실제 백엔드에서는 아직 확인하지 않았다.
