# 2026-11-09 고객 이용 현황 (와이어프레임 → 코드, 묶음 4)

브랜치: `feat/customer-usage-status` (origin/dev 기준)

## 추가
- **이용 현황** `/my-dining/status` (`?ticket=waiting-{id}` / `reservation-{id}` 로 팝업 바로 열기)
  - 진행 중: 노란 표(웨이팅 번호, 예약 시각), 지난 이용: 회색 표 최근 10건
  - 진행 중 웨이팅은 상세(GET /api/user/waitings/{id})로 순서, 앞 팀 수 표시
  - 입장 호출이면 표 안에 "H:MM 안에 매장에 와주세요" + 남은 시간 + **가는 중** 버튼 (POST /api/user/waitings/{id}/accept)
  - 응답 후 "가는 중이라고 알렸어요" + 알린 시각, 입장 기한
  - "자세히" 팝업: 큰 표 + 정보(인원, 순서, 접수 시각, 매장 주소·전화 / 이용 시간, 예약번호, 요청·확정·취소 시각)
    + 매장 보기 / 웨이팅 취소 / 리뷰 쓰기 / 예약 변경, 취소(예약 상세로 이동)
- **마이다이닝**: 전체 / 진행 중 / 지난 이용 칩 필터, 상단 "이용 현황 N" 버튼, 진행 중 웨이팅의 "순번 보기"는 이용 현황 팝업으로
- **웨이팅 화면** 문구: "가는 중" 버튼, "가는 중이라고 알렸어요", 호출 후에는 라벨을 "입장 호출" 로 유지
- 목 호출 알림 문구 "N분 안에 매장에 와주세요"

## 남은 것
- 예약 팝업의 예약금, 테이블 번호는 고객 예약 상세 응답에 없어 표시하지 않음
- MSW 로만 확인 (데모 대기열 진행으로 호출 → 가는 중 응답까지 확인)
